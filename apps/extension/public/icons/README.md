# Icons

Place the following PNG icon files here before building:

- icon16.png  (16×16)
- icon32.png  (32×32)
- icon48.png  (48×48)
- icon128.png (128×128)

You can generate them from the SVG source in `docs/assets/icon.svg`
using Inkscape, Figma, or any image editor.

The icon should be a white play-triangle on a
purple-to-indigo gradient background (#6366f1 → #a855f7).
